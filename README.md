# Многопоточная классификация случайных чисел

Программа генерирует 100 000 случайных чисел в диапазоне от 10 до 9999 и параллельно классифицирует их на три категории: двузначные, трёхзначные и четырёхзначные. Для безопасного подсчёта используются атомарные переменные `AtomicInteger`, что исключает блокировки и гонки данных.

## Как это работает

- `NumberGenerator` — утилита для генерации случайных чисел в заданном диапазоне.
- `NumberChecker` — поток, который проверяет весь массив чисел и увеличивает соответствующий счётчик, если число удовлетворяет условию.
- `Main` — создаёт массив, запускает три потока (по одному на категорию) и выводит итоговые количества.

Пример вывода
text
Двузначных чисел: 923 шт.

Трёхзначных чисел: 9045 шт.

Четырёхзначных чисел: 90032 шт.

Ключевые особенности
Многопоточная обработка данных (3 потока).

Использование AtomicInteger для атомарного инкремента счётчиков.

Отсутствие блокировок (synchronized) — высокая производительность.

Простая и расширяемая архитектура.
